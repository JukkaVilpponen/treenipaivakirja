# Treenipäiväkirja

Selainohjelmoinnin harjoitustyö. Sovelluksella voi lisätä treenejä (päivä, laji, kesto, teho, ulkona/sisällä, muistiinpanot), suodattaa niitä lajin ja haun mukaan, nähdä yhteiskeston ja poistaa treenejä.

**Tekniikat:** React (Vite), axios, Node.js ja Express. Data on palvelimen muistissa.

## Käynnistys

```
cd backend
npm install
npm run dev
```

Toisessa terminaalissa:

```
cd frontend
npm install
npm run dev
```

Sovellus aukeaa osoitteessa http://localhost:5173.
